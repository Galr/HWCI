How the bench works

  1. PartSTEP → mass, inertia, CG offset from the tilt axis
  2. ModelGimbal with motor, friction, sensors and a re-tuned control loop
  3. SearchEach requirement's envelope is searched for the scenario that breaks it
  4. MutantsSeeded defects test whether the requirement set would notice
Proof of concept. The gimbal model and every default number are illustrative, not a product specification. Geometry is read with OpenCascade (WebAssembly) in your browser; files never leave this machine.
